# Un canari pour détecter la dérive

Un skill simple : préfixer chaque phrase par un mot-clé ("Misu") quand il est actif

<v-click>

- Le préfixe doit rester visible à chaque réponse, sans exception
- S'il disparaît => le contexte est dilué, compacté, ou l'agent dérive des instructions
- Signal visuel, sans avoir à relire tout l'échange

</v-click>

<v-click>

=> Un repère simple pour savoir quand ouvrir une nouvelle session

</v-click>

<v-click>

Quand l'utiliser ?

=> Au début de son usage du dev agentique pour prendre l'habitude de nettoyer régulièrement ses sessions 

=> Durant une longue session.

</v-click>
